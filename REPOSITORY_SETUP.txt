MISSION COMPANION MASTER — REPOSITORY SETUP

1. Create a new GitHub repository named:
   mission-companion-master

2. Extract this ZIP.

3. Upload the CONTENTS of the Mission-Companion-Master folder to the repository root.
   Do not upload the enclosing folder itself.

4. Commit the files to the main branch.

5. In GitHub, open Settings > Pages.

6. Under Build and deployment, select GitHub Actions.

7. Open the Actions tab and wait for Deploy Mission Companion to complete.

8. GitHub will display the public Pages URL.

LOCAL RUNNING

Windows:
Double-click RUN_LOCAL_WINDOWS.bat and open http://localhost:8000

Mac:
Double-click RUN_LOCAL_MAC.command and open http://localhost:8000
If macOS blocks it, right-click the file and choose Open.

SECURITY

Do not place an OpenAI API key in this repository. Each browser user must provide their own key. A shared key requires a secure backend.
