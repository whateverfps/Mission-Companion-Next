# Mission PMIS Roadmap

## Mission PMIS 1.x — Stable Application
- Keep Excel as the backend.
- Improve user experience and information flow.
- Harden Reports, Meeting Mode, Field Mode, Engineering Mode, and Campus navigation.
- Maintain standalone ZIP and GitHub Pages deployment options.

## Mission PMIS 2.x — Drawing and Room Navigation
- Interactive floor plans.
- Clickable rooms.
- Room-level risks, questions, photos, and notes.
- Better document/photo panels.

## Mission PMIS 3.x — Intelligence Layer
- Historical snapshots.
- Project replay / time machine.
- Readiness trend analysis.
- Executive decision summaries.

## Mission PMIS Long-Term Rule
Do not rewrite the backend unless the operational need is clear. Excel remains the reliable engine until a database is justified.
