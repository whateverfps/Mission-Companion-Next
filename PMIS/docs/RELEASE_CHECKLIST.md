# Release Checklist

Before shipping a Mission PMIS release:

- [ ] App opens from extracted folder.
- [ ] App opens from GitHub Pages/local server.
- [ ] Campus map displays correctly.
- [ ] Workbook upload works.
- [ ] Building Browser opens and selects buildings.
- [ ] Meeting Mode opens.
- [ ] Field Mode opens if present.
- [ ] Engineering Mode opens.
- [ ] Reports Center opens.
- [ ] Print Current works.
- [ ] Print All Buildings works.
- [ ] No literal `${...}` template text visible.
- [ ] No missing map/icon images.
- [ ] No references to `C:\Users`, `%TEMP%`, or local absolute paths.
- [ ] ZIP is extracted before final test.
